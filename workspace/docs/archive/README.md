# Arquivo Documental

Esta pasta guarda documentos historicos, snapshots operacionais, auditorias datadas e memoria de remediacoes que nao devem mais competir com a documentacao viva do OpenClaw.

Regra:
- se um documento descreve um estado pontual no tempo, uma remediacao datada ou uma auditoria concluida, ele deve viver em `workspace/docs/archive/`;
- documentos em `workspace/docs/` devem representar contrato ativo, operacao viva ou referencia corrente.
